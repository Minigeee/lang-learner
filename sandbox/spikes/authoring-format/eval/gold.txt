# Gold set for the zh analyzer: S1-level sentences, stressing polyphones.
# Format: tokens separated by spaces; a Han token is surface/reading; punctuation is bare.
# Readings are CITATION readings (no sandhi): 不 is always bu4, 一 always yi1, 3+3 stays 3+3.
# Neutral tone is 5; ü is v; erhua is a separate r5 syllable (哪儿 na3r5), following CC-CEDICT.
# A trailing "# low: …" flags my own low confidence in that sentence's gold.
#
# Segmentation guideline (written before running any tool):
#  - A token is a lexicalized word: 我们, 银行, 觉得, 睡觉, 吃饭, 起床, 回家, 这个, 一点儿, 一下, 一起, 为什么.
#  - Free combinations are split: 喝 咖啡, 买 东西, 很 好, 不 是, 没 去, 一 个, 三 本 书, 桌子 上.
#  - Aspect and structural particles are their own tokens: 了, 着, 过, 的, 地, 得.
#  - Lexicalized negatives are one token (没有, 不要 "don't", 不行, 不用); a negated verb is two (不 去).
#  - A-not-A is three tokens (行 不 行, 好 不 好).

Lesson step 3 · Explain (≤200 words, one figure)

1.13 · 不 vs 没 · Explain
没 looks back. 不 covers habits and what's ahead.
Both translate as "not", which is the trap: English gives no clue. The question is when. If the action would have been in the past, Chinese uses 没. For habits, plans and refusals it uses 不.
✗ 我昨天不去。
✓ 我昨天没去。 I didn't go yesterday.
他没去。 tā méi qù
他不去。 tā bú qù
Go deeper: why is it 没有, never 不有?

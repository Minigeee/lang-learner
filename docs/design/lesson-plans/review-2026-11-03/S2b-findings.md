# S2b dependency review

Scope: `docs/design/lesson-plans/S2b.md`, units 2.16–2.32. Upstream: S1 and S2a. Rule applied: every S2 unit assumes all of S1 (doc 03 S2 header), so "off-path" means an S2 dependency outside the unit's doc 03 prereq closure, or an S1 dependency that S1 doesn't actually teach. Per the user's later guidance, edges are unit-level only, and fixes are additive (new prereq edges, vocab moves, wording). No S2b gap needs a new unit (see the end of Proposed prereq edges).

S2 prereq closures used (from doc 03 §1.8, S2 units only): 2.16 {}, 2.17 {2.16, 2.2, 2.1}, 2.18 {}, 2.19 {}, 2.20 and 2.21 {2.3, 2.2, 2.1}, 2.22 {2.13, 2.5, 2.4, 2.1}, 2.23 {2.16}, 2.24 {2.10, 2.23, 2.16}, 2.25 {2.5, 2.22, 2.23, 2.13, 2.4, 2.16, 2.1}, 2.26 {2.1, 2.11, 2.10, 2.2, 2.14, 2.13, 2.4}, 2.27 {2.19, 2.12, 2.11, 2.10, 2.2, 2.1}, 2.28 {}, 2.29 {2.13, 2.5, 2.22, 2.4, 2.1}, 2.30 {2.29 and its closure}, 2.31 {}, 2.32 all of S2 (not gated).

## Summary
- **2.21a's scored contrast relies on 2.20, which isn't a prereq of 2.21.** The C2 practice has "three say how many times (次 or 遍), one says how long (2.20a)". Add 2.20 → 2.21. 2.21c also mixes in 又…又 from 2.17b, and the 又 vocab card is placed at 2.17b, so add 2.17 → 2.21 too.
- **2.31 (real-speed speech) has only S1 prereqs, but its fillers come from S2a and S2b.** 然后, 其实 and 那 each carry `needed_by … 2.31` in the vocab files, yet their homes (2.11, 2.19, 2.27) are off 2.31's path. 就是 needs 就 (2.12). As written, the app could schedule an unscripted-corpus lesson right after S1. Add 2.27 → 2.31, which brings in 2.19, 2.12 and 2.11 transitively.
- **Description lessons rely on adjectives from 2.17.** 2.24a's opener needs 干干净净 (干净 is placed at 2.17b), and 2.24b's core example is 慢慢地走 (慢 at 2.17a; 慢慢 is only in the post-S2 queue). Add 2.17 → 2.24.
- **2.20 relies on 2.11 and 2.10.** 2.20b's scored items "need a context that closes the stretch (以前, 后来)", both taught in 2.11. 2.20a asks 多长时间, and 长 *cháng* is placed at 2.10a. Add 2.11 → 2.20.
- **2.23 is reachable without 2.6 or the "fast" sense of 快.** 2.23a interleaves 得 *děi* (2.6b), and 2.23b's opener and faces turn on 快 "fast", whose only vocab row is 2.2c's 快…了. Add 2.6 → 2.23, and add a 快 "fast" sense row at 2.23b.
- **2.28 and 2.16 have path gaps.** 2.28's prereqs are all S1, but 2.28c interleaves 2.17a's 有点儿/一点儿, so add 2.17 → 2.28. 2.16d's frame word 跟 is taught in 2.8b. The plan already proposes 2.8 → 2.16, but doc 03 still lists only "1.3, 1.6".
- **Vocab placement and the plans disagree on S1 number and degree words.** 一点儿 is placed at lesson 1.13d and 百 at lesson 1.13a, but neither S1 lesson uses the word, and S2b teaches both as new (2.16c, 2.18a). The place-value set is spread over 1.4a (十, plus an unused 零), 1.13a (百) and 2.18a (千, 万), and 2.18a also holds 分/毛/角, which it doesn't teach.
- **Six lesson targets are mis-tiered.** 看起来 (2.22d), 慢慢 (2.24b) and 偷 (2.30a's theft context) are in the post-S2 queue. 左右 (2.18b) and the filler 就是 (2.31a) are in no vocab file. 再 (2.21b) is in the S1 queue.
- **Minutes don't count `main` videos.** The README Video row says the minutes count the video, yet 2.28d lists two full mains (18:05 + 6:23) at "~6 min", and 2.24c lists a 16:43 main. The stated "5.3 h of lesson cores" understates S2b, in a stage doc 03 already calls "no slack".
- **One skill card tests the wrong thing.** 2.20c's C6 gaps the split verb's second half with sound-alike tiles, which tests syllable decoding rather than holding the split verb open.
